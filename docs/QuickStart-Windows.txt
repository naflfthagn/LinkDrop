轻传 LinkDrop 1.0.0 · Windows 快速开始
========================================

1. 请把 ZIP 解压到固定目录。exe 旁边的 LinkDrop.exe.config 和 BouncyCastle.Crypto.dll 必须保留。
2. 双击 LinkDrop.exe。
3. 首次启动若出现 Windows 防火墙提示，请允许“专用网络”。
   如果没弹窗，也可在应用内打开“设置 → 修复防火墙”。
4. 确保电脑网络为“专用网络”，并与手机连接同一个 Wi-Fi。

首次配对：
1. 电脑端点击“生成安全码”，记住屏幕上的 6 位安全码。
2. 手机安装 LinkDrop-Android-1.0.0.apk 并打开。
3. 手机在“附近的电脑”中选择这台电脑；如果看不到，点击“手动连接”，
   输入电脑界面上显示的局域网地址和端口（默认 48622）。
4. 核对手机和电脑显示的安全码完全一致。
5. 在电脑上点击“允许配对”。

以后：
- 两端都启动轻传，会自动连接。
- 手机点“发送文件”选择文件；电脑点“发送文件”或把文件拖入窗口。
- 手机收到的文件保存在“下载/LinkDrop”；电脑收到的文件保存在
  “下载\LinkDrop”，可在设置中修改。
- 若手机看不到电脑，优先检查同一 Wi-Fi、防火墙和“专用网络”，
  然后点击“重新扫描”或用“手动连接”。

安全提示：
- 应用不上传云端，文件只在同一局域网内点对点传输。
- 如果安全码不一致，请取消配对并检查网络。
- 电脑端未做商业代码签名，SmartScreen 可能提示；可选择“仍要运行”。

版本：1.0.0（2026-10-20）
